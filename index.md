## Project Showcase

### Project 1: Analysis of European Cities Starting with the Letter "Z"

**Research Question:**  
How are European cities whose names start with the letter "Z" distributed across the continent, and can we visualize their spatial pattern using geospatial analysis?

**Visualization:**

![Dot density plot](https://github.com/dee663385/data-science-project/raw/main/fig1.png)

**Findings:**  
The full dataset contains 3,173,958 city records, of which 898,604 are European. Among European cities, only a small fraction have names starting with "Z", and these are spatially sparse — the Voronoi visualization shows each cell covering a relatively large area. Population values for many small Z-cities are missing, which limits population-based comparison.

**Limitation:**  
The analysis relies on a hard-coded country-code list to define "Europe" and has many missing population values, which may affect completeness.
